StackTabs Privacy Policy

Last updated: 2026

Overview

StackTabs is a browser session manager that allows users to save and restore browser tabs and windows. The extension is designed with privacy as a core principle.

Data Collection

StackTabs does NOT collect, transmit, store, or sell any personal information.

Browsing Data

All saved tabs, windows, spaces, notes, and reminders are stored locally in the user's browser using Chrome local storage. This data never leaves the user's device.

No External Servers

StackTabs does not upload browsing history or saved tab information to any external server.

Permissions Usage

  • tabs – Used only to save and restore tabs selected by the user.
  • storage – Used to store saved sessions locally.
  • notifications – Used to show reminders and confirmations.
  • alarms – Used for reminder scheduling.

Advertisements

StackTabs may optionally display a rewarded advertisement to unlock extended dashboard usage. Viewing advertisements is optional and does not require personal data.

Third-Party Services

The extension may open a webpage hosted on GitHub Pages to display optional rewarded advertisements. No browsing activity or saved tab data is shared with that page.

Data Sharing

StackTabs does not sell, share, or transfer user data to any third party.
