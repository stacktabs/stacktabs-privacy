Privacy Policy for StackTabs

Last updated: 2026

StackTabs is a browser extension designed to help users save, organize, and restore browser tabs and windows. Your privacy is important, and StackTabs is built to operate with minimal data usage while providing its core functionality.

Data Collection

StackTabs accesses the titles and URLs of open browser tabs using the Chrome "tabs" permission. This data is required for the core functionality of saving and restoring tab sessions.

No personally identifiable information such as name, email address, or account information is collected.

Data Storage

All saved tab sessions, spaces, reminders, and settings are stored locally within the user's browser using the Chrome storage API.

StackTabs does not transmit tab data or browsing data to external servers.

Data Sharing

StackTabs does not sell, share, or transfer user data to third parties.

Secure Transmission

If the extension communicates with external services in the future (for example for optional features such as payments or updates), all communication will occur over secure HTTPS connections.

User Control

Users have full control over their stored data. All saved tab data can be deleted at any time from within the extension or by removing the extension from the browser.

Changes to This Policy

This privacy policy may be updated in the future if new features are added.
